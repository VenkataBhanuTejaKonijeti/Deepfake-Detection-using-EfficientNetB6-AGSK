# Deepfake Detection using EfficientNetB6-AGSK

## 📌 Project Overview

This project focuses on detecting deepfake images using a deep learning–based approach built on **EfficientNetB6** enhanced with **AGSK (Adaptive Global Spatial Kernel)**. The model aims to accurately distinguish between real and manipulated facial images by learning high-level spatial and texture features.

Deepfakes pose serious threats to digital trust, misinformation control, and personal security. This project contributes to combating such threats through an efficient and scalable deep learning solution.

---

## 🚀 Key Features

* Deepfake detection using EfficientNetB6 architecture
* Integration of Adaptive Global Spatial Kernel (AGSK)
* High accuracy in classifying real vs fake images
* Robust feature extraction for facial forgery detection
* End-to-end training and evaluation pipeline

---

## 🧠 Model Architecture

* **Base Model:** EfficientNetB6 (pre-trained)
* **Enhancement:** Adaptive Global Spatial Kernel (AGSK)
* **Output:** Binary classification (Real / Fake)
* **Loss Function:** Binary Cross-Entropy
* **Optimizer:** Adam
